# 榆林市图书馆小程序原型

本目录是网页二维码连接的小程序端，不包含独立 App。当前原型覆盖：

- 入馆查看约 100 副 Rokid Max 余量，选择时段并生成取镜码
- 扫描图书条码，查看读过/正在读的匿名同好与区域级位置
- 留下书旁留言，并主动选择是否允许被同好发现
- 按阅读兴趣查看相关馆藏、馆内活动和 AR 路线推荐
- 使用手机相机体验书封/地点两种轻量 AR 内容

## 运行

1. 打开微信开发者工具，导入本 `miniprogram` 目录。
2. 体验阶段可继续使用 `project.config.json` 中的 `touristappid`。
3. 发布前替换为已备案小程序的真实 AppID，并根据后端域名补充 request 合法域名。

当前眼镜库存、匿名同好、推荐内容和 AI 场景识别均为前端样机数据；正式上线需要对接馆藏、读者授权、设备库存及内容审核服务。用户位置只应保存到馆内区域级，不采集或展示精确座位。
